# Специфікація підготовки даних та компіляції (Needle Dataset)

Цей каталог містить інструменти для підготовки та автоматичної компіляції датасетів для локальної ШІ-моделі **Needle**.

## 1. Структура папок тасок

Кожне нове завдання (мова чи спеціалізація) повинно мати свою окрему папку всередині цієї директорії:

```text
training_data/
├── compile_dataset.py       # Головний скрипт-компілятор
├── README.md                # Цей файл документації
├── ua_en/                   # Папка таска для української мови
│   ├── raw_data.txt         # Ваші сирі текстові дані
│   └── train_data.jsonl     # Скомпільований файл (генерується автоматично)
└── jp_en/                   # Папка таска для японської мови
    ├── raw_data.txt         # Ваші сирі текстові дані
    └── train_data.jsonl     # Скомпільований файл (генерується автоматично)
```

## 2. Специфікація сирого формату даних (`raw_data.txt`)

Для спрощення генерації даних через інші ШІ (наприклад, ChatGPT, Claude) або ручного редагування, ми використовуємо **багаторядковий текстовий формат**.

* Кожен приклад завершується роздільником з трьох дефісів `---`.
* Поля можна дублювати (наприклад, написати кілька `action:` або `patient:`). Компілятор автоматично об'єднає їх у чистий JSON-масив рядків `["дія_1", "дія_2"]`.
* Відсутні поля писати не обов'язково — компілятор автоматично підставить порожній масив `[]`.

### Приклад складного блоку з кількома діями:
```text
query: пулль зміни з гіта та онови трансформ
action: пулль
action: онови
patient: зміни з гіта
patient: трансформ
---
```

## 3. Команда компіляції

Щоб перетворити ваші текстові блоки у валідний екранований `.jsonl` файл для навчання, виконайте у терміналі WSL команду (вказавши назву вашої папки у параметрі `--task`):

```bash
# Компіляція для японського таска
python3 librarian_ai/training_data/compile_dataset.py --task jp_en

# Компіляція для українського таска
python3 librarian_ai/training_data/compile_dataset.py --task ua_en
```

Після виконання команди у відповідній папці з'явиться готовий файл `train_data.jsonl`, який буде використаний скриптом `train.py` під час навчання.
