# Інструкція з донавчання моделі Needle (Fine-Tuning Pipeline)

Цей документ описує архітектурний розподіл процесів розробки для проекту SboxAstGraph.

## 1. Архітектурний розподіл (GPU vs CPU)

Для досягнення максимальної продуктивності процеси розділено:
* **Навчання (WSL2 + GPU):** Виконується в Linux-середовищі WSL2, оскільки JAX не підтримує прискорення NVIDIA GPU нативно на Windows. Наявність GPU дозволяє провести Fine-tuning за 3 хвилини замість годин на CPU.
* **Робота в додатку (Windows + CPU + ONNX):** Фінальна модель запускається на процесорі Windows через ONNX. Це забезпечує миттєвий запуск (sub-100ms) та низьке споживання оперативної пам'яті (RAM) без затримок на ініціалізацію CUDA.

## 3. Консольні команди для запуску навчання у WSL2

Кожного разу, коли вам потрібно оновити або донавчити модель на нових даних:

1. Відкрийте ваш звичайний термінал PowerShell та перейдіть в Ubuntu:
   ```powershell
   wsl
   ```
2. Перейдіть у робочу папку проєкту (яка лежить на Windows):
   ```bash
   cd /mnt/c/Users/yenro/Desktop/sbox_ast_graph
   ```
3. Активуйте Linux-оточення (воно лежить всередині файлової системи Linux):
   ```bash
   source ~/sbox_ast_graph/.venv_wsl/bin/activate
   ```
4. (Опціонально) Оновіть ваш файл з даними `train_data.jsonl` на Windows.
5. Запустіть скрипт Fine-tuning:
   ```bash
   python3 librarian_ai/train.py
   ```
6. Результат навчання (файл ваг `needle_ft.pkl`) буде автоматично збережено прямо на ваш Windows-диск за шляхом:
   `librarian_ai/models/fine_tunes/ua_en/needle_ft.pkl`

---

## 4. Вихід із середовища Linux

Після завершення навчання, щоб повернутися до розробки на Windows:

1. Деактивуйте віртуальне оточення Linux:
   ```bash
   deactivate
   ```
2. Вийдіть із WSL2 назад у PowerShell Windows:
   ```bash
   exit
   ```
Тепер ви знову у рідній Windows-консолі.
